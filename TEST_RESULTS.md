# Перевірка сервера Дитсадок

Дата: 16 листопада 2026 року.

Середовище перевірки: Python 3.12, Flask 3.1.3, MySQL Connector/Python 9.7.0, MySQL Community Server 8.4.7.

- **22 тести pytest — успішно.** Перевірено CRUD усіх 11 таблиць, складений первинний ключ, зв’язки 1:M і M:M, зовнішні ключі, дублікати, валідацію дат і сум та серіалізацію DTO.
- **79 запитів колекції Postman через Newman — успішно.** Усі 79 перевірок HTTP-кодів пройшли.
- Після прогону колекції залишилося по 10 початкових записів у таблицях, крім group_enrollments, де залишилося 12.
- Bootstrap створив відсутню базу, таблиці та початкові дані; HTTP-перевірка підключення повернула успіх.
- Після ручної зміни імені працівника сервер перезапущено; змінене ім’я збереглося.
- Перевірено додавання відсутнього district, створення відсутньої employee_groups, збереження частково заповнених баз та повторне виконання SQL-міграції district.
- Перевірено збереження і повторне читання локальних налаштувань із пробілами, лапками та Unicode.

Автоматичні перевірки Python-запуску виконано на Linux. START_SERVER.bat підготовлений для Windows і потребує встановлених Python 3.10+ та MySQL Server. Фактичне виконання BAT у Windows у цьому середовищі не проводилося.
